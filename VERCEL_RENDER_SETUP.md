# Vercel Frontend + Render Backend Setup Guide

## 🎯 Architecture Overview

- **Frontend:** Vercel (Next.js)
- **Backend:** Render (FastAPI + PostgreSQL)
- **Database:** Render PostgreSQL

## 📋 Prerequisites

1. **GitHub Repository** with your code
2. **Vercel Account** (free tier available)
3. **Render Account** (free tier available)

## 🚀 Step 1: Backend Deployment (Render)

### 1.1 Deploy Backend with render.yaml

1. Go to Render Dashboard
2. Click **"New +"** → **"Blueprint"**
3. Connect your GitHub repository
4. Select **render.yaml** file
5. Click **"Apply Blueprint"**

### 1.2 Manual Backend Setup (Optional)

If blueprint doesn't work:

1. **Create Web Service:**
   - Click **"New +"** → **"Web Service"**
   - Connect GitHub repository
   - Root directory: `web-platform/backend`
   - Runtime: Docker
   - Dockerfile path: `Dockerfile`

2. **Create PostgreSQL Database:**
   - Click **"New +"** → **"PostgreSQL"**
   - Database name: `logixa_flow`
   - User: `logixa_user`

3. **Configure Environment Variables:**
   ```env
   DATABASE_URL=<auto-generated from Render>
   ENVIRONMENT=production
   JWT_SECRET=<generate secure secret>
   ADMIN_PASSWORD=<generate secure password>
   API_SECRET_TOKEN=<generate secure token>
   CORS_ORIGINS=https://*.vercel.app
   REQUIRE_AI_KEY=false
   ```

### 1.3 Get Backend URL

After deployment, Render will provide:
```
https://logixa-flow-backend.onrender.com
```

**Copy this URL** - you'll need it for Vercel configuration.

## 🌐 Step 2: Frontend Deployment (Vercel)

### 2.1 Deploy Frontend

1. Go to Vercel Dashboard
2. Click **"Add New Project"**
3. Import your GitHub repository
4. Configure settings:
   - **Framework Preset:** Next.js
   - **Root Directory:** `web-platform/frontend`
   - **Build Command:** `npm run build`
   - **Output Directory:** `.next`

### 2.2 Configure Environment Variables

In Vercel → Project → Settings → Environment Variables:

```env
NEXT_PUBLIC_API_URL=https://logixa-flow-backend.onrender.com
```

**Replace with your actual Render backend URL!**

### 2.3 Deploy

Click **"Deploy"** button. Vercel will:
1. Build your Next.js app
2. Deploy to edge network
3. Provide URL like: `https://logixa-flow.vercel.app`

## 🔗 Step 3: Configure CORS & Integration

### 3.1 Update Render Backend CORS

In Render Dashboard → Backend Service → Environment Variables:

```env
CORS_ORIGINS=https://*.vercel.app,https://localhost:3000
```

### 3.2 Test Integration

1. Open Vercel deployed frontend
2. Try to access admin: `https://your-vercel-domain.vercel.app/admin/login`
3. Backend API should work through CORS

## 🐛 Troubleshooting

### Issue 1: CORS Errors

**Error:** `Access-Control-Allow-Origin` header missing

**Solution:**
1. Check Render backend CORS_ORIGINS setting
2. Ensure Vercel domain is included
3. Redeploy backend after changes

### Issue 2: API Connection Failed

**Error:** `fetch failed` or network error

**Solution:**
1. Verify NEXT_PUBLIC_API_URL in Vercel
2. Check Render backend is running
3. Test backend API directly: `https://your-backend.onrender.com/docs`

### Issue 3: Admin Login Failed

**Error:** Invalid credentials

**Solution:**
1. Check Render environment variables for ADMIN_PASSWORD
2. Use the generated password from Render
3. Reset admin password if needed

### Issue 4: Database Connection

**Error:** Database connection failed

**Solution:**
1. Verify Render PostgreSQL is running
2. Check DATABASE_URL is properly configured
3. Ensure database is accessible from backend service

## 🔒 Security Best Practices

1. **Never commit .env files** - Use environment variables
2. **Generate secure secrets** - Use Render's generateValue feature
3. **Limit CORS origins** - Only allow your Vercel domain
4. **Use HTTPS** - Both Vercel and Render provide free SSL
5. **Monitor logs** - Check Render logs for suspicious activity
